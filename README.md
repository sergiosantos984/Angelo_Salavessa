# Ângelo Salavessa — website

Pages: index.html (Home) · about.html · lifestyle.html · travel.html · tattoos.html · the-last-soul.html · journal.html (+ article.html for each story) · contact.html · 404.html
Design: assets/site.css · Behaviour: assets/site.js · Content: content.json · Photos: images/
Editor: admin.html (the "Edit site" button in the footer)

Look: warm ivory #EAE7E0 + charcoal #292B29, with terracotta #C66B45 as the one loud colour.
Old links (index.html#booking, #work, #artist…) redirect to the new pages automatically.

## Editor setup (once per device)
1. Open the website → Edit site → sign in.
2. Publishing setup: create a GitHub access key (fine-grained token, only this repository, Contents: Read and write), paste it, Save & test.
3. Edit → Publish → the site updates in about a minute.
