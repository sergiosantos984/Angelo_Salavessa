# Ângelo Salavessa — website

- `index.html` — the website
- `admin.html` — the editor (open it from the "Edit site" button in the footer)
- `content.json` — all text, settings and the portfolio list; the editor saves here
- `images/` — photos (new uploads go to `images/uploads/`)

Look: black, amber red #95191D, off-white #F6F6EA, with yellow #FBE525 only on booking buttons.

## Editor setup (once per device)
1. Open the website → **Edit site** → sign in.
2. Go to **Publishing setup** and follow the steps there to create a GitHub access key
   (fine-grained token, only this repository, Contents: Read and write).
3. Paste it, press **Save & test**. From then on: edit → **Publish** → the site updates in about a minute.

The key is stored only in that browser. If a device is lost, delete the key on GitHub.
